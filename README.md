# MangaReader Clone - Landing Page

Esta es una landing page semántica y responsiva construida exclusivamente con HTML5 y CSS3, inspirada en plataformas de lectura de manga como MangaDex.

## Características
* Estructura basada en etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* Diseño estructurado con CSS Flexbox y CSS Grid.
* Uso de variables CSS para el esquema de colores.
* Interacciones visuales con pseudoclases (`:hover`, `:focus-visible`).
* **Cero JavaScript**, cumpliendo con los requisitos del proyecto.

## Instrucciones de ejecución
Para visualizar este proyecto localmente:
1. Clona este repositorio en tu computadora.
2. Abre la carpeta del proyecto en Visual Studio Code o Cursor.
3. Instala y activa la extensión **Live Server**.
4. Haz clic derecho sobre el archivo `index.html` y selecciona **"Open with Live Server"**.
5. El proyecto se abrirá automáticamente en tu navegador predeterminado.
